# bazis-uploadable 2.6.3

Requires bazis 2.7.0. Documentation only; the code is the one of 2.6.2.

## Documentation

- `FileUploadRouteSet` and its subclasses restrict the files themselves (their
  `restrict_queryset`): `permit.W002` of bazis-permit does not apply to them from
  bazis-permit 2.10, and they need no `permit_public = True`, which says the files are
  public.
