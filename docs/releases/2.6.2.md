# bazis-uploadable 2.6.2

Requires bazis 2.7.0. Documentation only; the code is the one of 2.6.1.

## Documentation

- The guide (`bazis/contrib/uploadable/AGENTS.md`) shows how to register the route set
  that widens the visible files instead of the bundled router (it serves the same URLs;
  do not register both), and says that "a file is visible with the object that references
  it" has no declarative form: it is written in `restrict_queryset`.
