# bazis-uploadable 2.7.0

Requires bazis 2.16.0: the core asks `restrict_queryset` for the objects a relationship
links with `link=True` and refuses a visible object it leaves out with 422
`ERR_RELATION_LINK`.

## Access control

- **`files_visible` on the route set of a model that references files.** `files_visible =
  ('file',)` (foreign keys, one-to-one or many-to-many fields to the files) makes the files
  of the objects a user sees through that route set (its `restrict_queryset` for `view`)
  visible to him: the list, the item and the download of the route of the files and
  `included` of the other routes. Several route sets add up. It replaces a subclass of
  `FileUploadRouteSet` that unions the `restrict_queryset` of several route sets.
  Only the route class that declares it in its own body counts (a subclass does not
  inherit it), and the visibility follows the objects, not the field permissions of the
  relation. `uploadable.E001` (`bazis_doctor`) reports a name that is no such relation and
  a declaration on an abstract route class.
- **A relationship links only the own files of the user.** A visible file of another user
  fails with `422 ERR_RELATION_LINK`, an invisible one with `403 ERR_RELATION_ACCESS` as
  before; an unchanged link is not checked.
- **Download with the access check:** `GET /uploadable/file_upload/{id}/download/` streams
  a file the user sees (401 without a user, 404 otherwise), as the media host should serve
  it: a raster image inline, any other file as an attachment, `nosniff`, a sandbox,
  `Cache-Control: private, no-store`. Private files can be kept out of the public media.

## Files the server generates

- `FileUpload.objects.create_for(author, name, content)` stores bytes, a text or a Django
  `File` as an uploaded file of `author`. The guide has a recipe of a PDF with reportlab
  and the DejaVu fonts of matplotlib (a pip package with their license), without a new
  dependency of the package.

## Guide

- The guide describes the migration cycle of a user model with a foreign key to an app
  whose models reference `FileUpload` (`CircularDependencyError`) and its recipe: the
  foreign key in a second migration of the users app.
- The guide is read by sections: its introduction maps them with when to read each (bazis-mcp
  serves it alone), and the items of the manifest are one line each, their details in the
  guide.

## Breaking changes

- A subclass of `FileUploadRouteSet` that widens `restrict_queryset` keeps linking every
  file it shows unless it returns the own files for `kwargs.get('link')` (see the guide).
- With bazis older than 2.16 `files_visible` would also let a user link the visible files
  of others: the requirement is raised.
