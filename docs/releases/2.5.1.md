# bazis-uploadable 2.5.1

Requires Bazis 2.4 and bazis-author 2.4 (with bazis-users).

## Fixes

- **The name of an uploaded file is "Название" in Russian**, as in bazis-permit and
  bazis-statusy: the catalog of the package translated the msgid `"Name"` as
  "Наименование". When two catalogs translate the same msgid, the first one in
  `LOCALE_PATHS` wins, so the title of the field depended on the packages a project
  installed and on their order. The Bazis packages now share the translation; a project
  that prefers another one translates `"Name"` in its own `locale`.
