# bazis-uploadable 2.4.0

Requires Bazis 2.4.

## Tools and AI agents

- The package ships `AGENTS.md` (setup, storage, the upload request, the size limit and
  access control) and `bazis_manifest.toml` for tools and AI agents (see `docs/agents.md`
  of Bazis). `tests/test_manifest.py` verifies the manifest.
- New system check (`manage.py bazis_doctor`): `uploadable.W001`, the bundled
  `FileUploadRouteSet` (`bazis.contrib.uploadable.router`), which has no access control,
  is registered. Register a subclass that requires a user or permissions instead.
