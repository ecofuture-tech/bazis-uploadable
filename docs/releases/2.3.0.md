# bazis-uploadable 2.3.0

Requires Bazis 2.3 (Django 6.1, FastAPI 0.142).

- **`BAZIS_FILE_UPLOAD_MAX_SIZE`**: the maximum size of an uploaded file in bytes; larger
  files are rejected with 413 and `ERR_FILE_TOO_LARGE`. `0` (the default) keeps uploads
  unlimited.
- The storage is a callable of the `file` field (`get_file_upload_storage`) instead of
  being assigned to the shared field object in `__init__` of every model instance. The
  migration `0003_file_storage_callable` brings the migrations in line with the model
  (`0002` referenced `FileSystemStorage`, which the model no longer declared, so
  `makemigrations` always produced a migration); it does not change the database.
- `size` returns 0 for any storage error of a missing file (`OSError`), not only
  `FileNotFoundError`.
- README: the bundled `FileUploadRouteSet` has no access control; projects should register
  a subclass that requires a user or permissions.
- Dependencies: `bazis>=2.3.0`, `python-multipart>=0.0.18`.
- CI runs the tests on Python 3.12–3.14 and with the lowest allowed dependency versions;
  releases are made with the Release workflow (see `CLAUDE.md`).
